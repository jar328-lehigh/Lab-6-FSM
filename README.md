# Lab-6-FSM

Marina Falzone & Jared Rabadam

This project implements a button debouncer, a Mealy finite state machine, and a Moore finite state machine in Verilog using Vivado. It is intended to be run on a BASYS 3 FPGA Board.

To simulate, upload all Verilog files to Vivado. To simulate, set desired testbench as top and run simulation.
